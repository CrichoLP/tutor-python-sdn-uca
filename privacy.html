Datos tratados por el plugin

La versión pública de Tutor Python SdN UCA es un plugin basado en instrucciones y archivos de referencia. No opera un servidor propio, no mantiene una base de datos propia y no solicita credenciales, información de pago ni datos personales para funcionar.

Conversaciones en ChatGPT

Las interacciones con el tutor se realizan dentro de ChatGPT y están sujetas a las políticas, configuraciones y prácticas de tratamiento de datos de OpenAI aplicables a la cuenta del usuario. El desarrollador del plugin no recibe automáticamente una copia de las conversaciones de los usuarios.

Soporte mediante GitHub

Si un usuario decide enviar un reporte mediante GitHub Issues, la información publicada allí puede ser visible públicamente. No deben incluirse contraseñas, datos personales, información académica sensible ni otros contenidos privados.

Cambios

Esta política puede actualizarse si cambian las capacidades del plugin o sus prácticas de datos. La versión vigente se publicará en esta página.
