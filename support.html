Cómo solicitar ayuda

Si encontrás un problema con el funcionamiento del plugin, una respuesta que no respeta la progresión de contenidos o una explicación pedagógica inadecuada, podés informarlo mediante un issue público en GitHub.

Abrir la sección de Issues en GitHub

Antes de publicar un reporte

No incluyas contraseñas, datos personales, información académica sensible ni contenido privado. Describí el problema y, si es útil, copiá únicamente el fragmento mínimo de la conversación necesario para reproducirlo.
